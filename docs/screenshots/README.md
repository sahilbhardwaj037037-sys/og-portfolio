# Portfolio screenshots

Genuine viewport captures from the local production build of OG Portfolio, captured in Google Chrome on October 24, 2026. Desktop: 1440 × 1000; mobile: 390 × 844 with touch emulation and device scale factor 1.

The desktop hero was captured after the original laptop loaded. Smile Care shows the independent screenshot gallery; ClientScout shows the CRM section. Mobile images show the actual collection and approved contact section. Existing interfaces, typography, media and disclosures were not retouched or composited.

PNG capture output was encoded as WebP (quality 84, method 6) for documentation. No runtime media was replaced. Original PNGs and capture scripts remain local ignored QA evidence.
